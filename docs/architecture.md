# 设计说明

```text
Windows 浏览器 ── WSL 已有 localhost 转发 ─┐
                                         ├─ 127.0.0.1:8765
WSL/Linux CLI ─── 本机 HTTP + Bearer 令牌 ─┘       │
                                           ASGI 安全校验
                                                │
                                     Starlette + Uvicorn/h11
                                       │                 │
                               SQLite 元数据      按 ID 存储的内容
                                       └────────┬────────┘
                                          定时过期清理
```

一个发布程序同时提供 CLI 和后台服务。所有持久状态受 `--home` 管理。默认使用回环 HTTP；显式配置的虚拟机模式使用指定内网 IPv4 + HTTPS + 具体主机 IP 白名单，不接受通配、公网绑定或网段白名单。

```text
主机浏览器 ── 已有 Host-only 网络 / HTTPS ── 虚拟机内网 IP:8765
                                             │
                                      真实来源 IP、Host、Origin 校验
                                             │
                                   同一个登录、上传和共享文件列表
```

远端浏览器只能使用短期登录凭证建立 HTTPS 会话，不能使用本地 CLI 内部密钥或停止服务。虚拟机内 CLI 连接配置的地址并验证证书，服务在自身地址上允许 CLI 访问。HTTPS 证书生成和检查使用内嵌 OpenSSL；私钥和配置仅写入应用数据目录，TLS 至少为 1.2。网络配置更新持有与存储相同的进程锁，必须先停止服务。

网页拖放和 CLI 上传使用同一个接口与共享列表，不携带传输方向。旧版方向字段在启动时通过事务迁移去除，保留原文件和标识。

私有目录中的内部密钥供 CLI 自动认证，并签发带独立用途签名的临时凭证：网页登录令牌默认 10 分钟有效，登录后生成默认 2 小时有效的 HttpOnly Cookie。两种凭证不能互相替代；登录令牌过期不会影响已建立的会话。页面启动时先检查 Cookie 会话，再决定显示共享列表或登录框，不把令牌写入浏览器存储。

上传需要明确的 Content-Length，最多 4 个并发上传；元数据数量上限 10000，HTTP 并发连接上限 32。上传先预留配额，在私有临时文件中逐块写入、计算摘要、fsync，内容重命名完成后再提交元数据。中断时撤销预留并清理临时内容。进程异常退出后的无记录内容在下次启动时回收。同一数据目录通过进程文件锁禁止多个服务同时访问。

下载期间持有文件租约，过期清理和手动删除会跳过正在使用的内容。CLI 校验大小及 SHA-256 后才保存目标文件；重名时生成新名称。原始文件和下载副本都不属于服务器的清理范围。

目录内容只作为 ZIP 存入中转站，后端不替用户写入任意目标目录。CLI 按用户明确传入的目标目录提取内容，校验每个条目并先写入临时目录；网页目录 ZIP 通过文件流计算 CRC32 和 Blob 组合生成，不需要 CDN 库。

发布物与 CPU 架构、glibc 基线相关。`BUILD-INFO.json` 记录构建环境和依赖版本；应定期更新解释器及依赖、测试并重新发布。现有虚拟环境为隔离环境，发布物不依赖它。单文件后台子进程使用 PyInstaller 的独立实例环境，避免启动命令退出后临时运行库被提前回收。

用户级安装由发布程序内置的 `installation` 模块执行，`install.sh` 和 `uninstall.sh` 仅负责调用该程序，不依赖目标系统 Python。安装记录保存在安装目录的 `.file-relay-install.json`；默认将 `~/.local/bin/file-relay` 链接到安装目录内的程序，并拒绝覆盖既有路径。默认数据目录从真实可执行文件路径推导，因此命令链接不会改变数据归属。卸载仅按安装记录撤销仍属于本安装的链接，持有默认数据目录的存储锁完成删除，默认保留数据。
