## 本次完善

此前服务绑定地址、客户端目的地址、来源地址校验和网页 Host/Origin 都限定回环，因此独立虚拟机无法直接提供网页给主机。v0.3.0 将这些位置按同一应用配置同步调整，同时保留默认回环模式。

新增具体内网绑定、主机 IP 白名单、强制 HTTPS、内嵌 OpenSSL 证书生成、指纹检查、Secure Cookie、严格 TLS 客户端验证、停止后原子更新配置和恢复回环模式。远端浏览器不能停止服务。本地 `stop` 等待监听退出，避免随后启动时误判旧服务仍在运行。

v0.3.0 测试覆盖 86 项，包含真实 TLS MemoryBIO 握手与加密数据、错误证书拒绝、未授权来源拒绝、Host/Origin 校验、远端网页上传下载、Cookie、配置失败回滚、运行中禁止改配置和回环恢复。
